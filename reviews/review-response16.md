An independent observer then captured Calculator becoming foreground and
receiving keyboard focus without a corresponding foreground WinEvent. A shell
activation notification did arrive. The final implementation supplements the
foreground WinEvent with HSHELL_WINDOWACTIVATED/HSHELL_RUDEAPPACTIVATED through

validate the current foreground before feeding normal recency handling.
Background creation/attention is not promoted, and duplicate inputs preserve
pending focus deadlines. Registration failure fails worker startup; registration
is removed on cleanup. RegisterShellHookWindow has a documented compatibility
caveat, so this is not a guarantee for every Windows build.
